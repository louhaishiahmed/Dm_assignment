# Campaign assets

Place the supplied image files in this folder using these exact filenames:

- `cr1.png` - the closed briefcase hero image and campaign slide 1
- `briefcase-open-can.png` - the open briefcase image with the can inside
- `cr2.png` through `cr5.png` - campaign slides 2 through 5
- `can.png` - optional standalone can image, currently not required by the page
- `logo.png` - optional logo; the page currently uses a text fallback in the header

Keep the original proportions and PNG format. If a file is missing, the page displays an expected-filename placeholder instead of a broken-image icon.
